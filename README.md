# togyz-lite

托古孜库马拉克（Togyz Kumalak / Toguz Korgool）极简版：中亚游牧民族的 2×9 坑播棋。
纯 Python 标准库，无第三方依赖。

## 玩法

- 棋盘：双方各 9 个坑，每坑开局 9 颗种子（共 162 颗）；另有双方各自的 kazan（得分坑）。
- 轮流从自己一侧选一个非空坑，逆时针逐坑播一颗；绕满一圈时跳过起点坑。
- 最后一颗若落在**对方**坑使其恰好 3 颗：吃掉这 3 颗；若自己还没有 tuz
  且不是对方第 9 坑，则改为把该坑认领为自己的 **tuz**（同时吃掉 3 颗）。
- tuz 是永久据点：以后任何种子落到 tuz 坑，直接进 tuz 主人的 kazan。
- 一方无子可走时终局：双方各自收走自己一侧残子，kazan 种子多者胜。

## 用法

```bash
python3 -m togyz_lite                 # 人机交互（中文）
python3 -m togyz_lite --auto --games 10 --seed 42        # AI 对 AI 演示
python3 -m togyz_lite --auto --games 10 --seed 7 --verbose
```

`--games` 局数、`--seed` 随机种子、`--verbose` 打印每局比分。

## 真实验证记录

- `py_compile` 通过。
- 8 项单元测试全过（/tmp/test_togyz_lite.py）：播种分布、tuz 认领（含同时吃 3 子）、
  已有 tuz 时直接吃子、tuz 收子、非法走法（走对方坑/空坑/错轮次）拒绝、
  完整对局种子守恒 162、无子可走结算。
- `--auto --games 10 --seed 42`：10 局全部正常结束（甲胜 9 / 乙胜 1 / 和棋 0）。
- 多种子平衡性抽查：纯随机 AI 下甲乙胜负接近（20 局约 10:9），规则无系统性偏向；
  贪心 AI 对局中甲（先手方记分侧）略占优，属弱 AI 产物。

## 诚实局限

- **简化规则**：tuz 认领是自动的（真实规则中玩家可选择吃子还是认领）；
  未实现开局 atsyrau 等变体规则；终局按"无子可走即收官"简化处理。
- **AI 很弱**：1 步贪心（吃子/tuz 加权 + 随机破平），不做深层搜索；
  熟悉规则的人类通常能赢。
- 文本棋盘，无图形界面/存档/悔棋；Python 3.10+。
